Video source settings

Without a key, this app tries to retrieve the latest videos using RR Buildings' public RSS feed through a third-party CORS proxy. If that proxy is unavailable, add your own YouTube Data API v3 key to load the complete uploads list in pages of 50.

The key is stored only in this browser's localStorage and sent to Google's API. For a personal localhost app, restrict it appropriately in Google Cloud. Don't publish an HTML file containing an unrestricted key.
